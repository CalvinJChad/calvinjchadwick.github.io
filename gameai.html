Stalker Enemy Behaviour Tree - Game AI Assignment

Created using Unreal Engine 5.6 - this project involved designing and implementing an artificial intelligence technique that can be used within a gameplay environment. For it, I decided to create a basic Stalker AI (inspired by enemies from games like Resident Evil, Amnesia: The Bunker and Alien: Isolation) using Behaviour Trees in Unreal Engine.

For this project, I began designing and visualizing the Behaviour Tree in draw.io, before implementing using Unreal Engine’s Behaviour Tree Visual Scripting as well as Blueprints.

This project not only gave me a lot of experience working with Unreal Engine Behaviour Trees, but it also gave me a lot more understanding into other artificial intelligence techniques such as Finite State Machines, Fuzzy Logic and Goal Oriented Programming. I greatly enjoyable part of this project came from researching into the AI behind some of the enemies that inspired it. A big inspiration came from the Xenomorph AI in Creative Assembly's Alien: Isolation and the Frictional Games' Amnesia: The Bunker. I hope to further develop this project in the near future, by implementing more interesting behaviours for the AI and maybe even trying other AI techniques.
