Gameplay Mechanics Development - Unreal Engine Assignment

Created using Unreal Engine 5.6 - this project involved designing and implementing a gameplay mechanic with functionality consisting almost entirely in C++. For it I, decided that I wanting to recreate the environmental physics objects Frictional Games' Amnesia series using Unreal Engine's physics systems.

For this project, I began prototyping the project using Unreal Engine's Blueprints. Once I had the mechanic finalised, I began converting said Blueprint code to C++ code. I then began polishing it further – with some UI indicating when an object can or is currently being grabbed. This project helped me gain a lot of experience working in Unreal Engine with C++ and Blueprints as well as adhering to Epic’s coding standard. It also gave me more experience in writing technical design documentations.
